# Pre-Proposal Statement

NOTE: 1 for each of the 3 to 5 titles chosen by the adviser (strictly word-processed)

## Project Title

Division Duel: A Quick-Tap Division Fact Recall Game for Grade 4 Learners

## Proponents/Researchers

Dainty Deanne M. Lamberto

## Scope of the Study

- Division Duel is a single-player mobile game designed to help Grade 4 learners build quick, accurate recall of basic division facts.
- It targets one specific skill: fast mental recall of division facts, an area where Grade 4 learners commonly need more practice.
- The game is meant for short, repeatable practice sessions that learners can do on their own, at home, without needing a teacher or parent to help.

## Limitations of the Study

- The game has one gameplay mechanic only (tap the correct answer); it has no storyline, chapters, or mini-games.
- It is single-player; there is no multiplayer mode or online play with other learners.
- It works fully offline once installed; no internet connection is needed to play.
- There is no companion website, user account system, or admin dashboard.
- It covers basic division fact recall only; it does not include multi-step word problems or other math topics.
- It runs on Android phones and tablets only (Android 10–14); it is not available on iOS or desktop.
- Scores are stored on the device only; there is no cloud save or backup.

## Project Design/Development Plan

### Program Specification

- One main game screen is reused for every round.
- A division problem appears on screen (for example, 56 ÷ 8) with a few possible answers; the learner taps the correct one before the timer runs out.
- Problems are pulled from an expandable list (each with the correct answer plus 2–3 wrong answers), so new problems can be added without changing the game's code.
- A countdown timer runs for each problem, with simple visual feedback for correct and incorrect taps.
- A running score counter and saved best score/time track the learner's progress.
- The game uses simple 2D bubble-style graphics and one-tap controls.

### Software Specification

- Game engine: Godot Engine 4.7
- Script language: GDScript
- Output: Android application (APK)
- OS: Windows 11 64-bit
- IDE: Visual Studio Code
- Works on: Android 10+
